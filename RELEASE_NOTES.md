# 🚀 Adventure Journal Mod v1.1.0 - POI Management System

**Expanda suas aventuras com gerenciamento completo de Pontos de Interesse!**

## 📖 O que há de novo na v1.1.0?

A versão 1.1.0 representa uma **evolução significativa** do Adventure Journal Mod, introduzindo um sistema completo de gerenciamento de POIs que transforma a forma como você organiza e navega em suas aventuras no Minecraft.

### ✨ **Principais Novidades**

�️ **Sistema Completo de Gerenciamento de POIs**
- **6 comandos avançados** para controle total dos seus pontos de interesse
- **Edição in-loco** de nomes e descrições
- **Remoção segura** com confirmação e feedback
- **Informações detalhadas** com cálculos de distância em tempo real

� **Navegação Inteligente**
- **Comando `/poi nearest`** encontra o POI mais próximo automaticamente
- **Cálculo de direção** (Norte/Sul/Leste/Oeste) para orientação
- **Detecção de dimensão** com indicadores visuais
- **Sugestões de teleporte** quando aplicável

🎨 **Interface Aprimorada**
- **Cores otimizadas** com substituição de azul claro por azul escuro
- **Modo detalhado** na listagem com distâncias e coordenadas
- **Feedback visual** completo em todas as operações
- **Documentação integrada** no livro de aventuras

## 🎮 Novos Comandos

### **Gerenciamento Avançado:**

```bash
# Remover um POI específico
/poi remove 2

# Editar apenas o nome
/poi edit 1 "Nova Casa Base"

# Editar nome e descrição
/poi edit 3 "Mina Premium" "Rica em diamantes e ouro"

# Ver informações completas
/poi info 1

# Listagem detalhada com distâncias
/poi list -d

# Encontrar POI mais próximo
/poi nearest
```

### **Funcionalidades Melhoradas:**

```bash
# Comandos originais mantidos e aprimorados
/poi add MinhaBase
/poi add "Castelo" "Projeto de construção épica"
/poi list
```
