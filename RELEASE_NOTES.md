# 🚀 Adventure Journal Mod v1.0.0 - Release Inicial

**Transforme suas aventuras do Minecraft em memórias duradouras!**

---

## 📖 O que é o Adventure Journal Mod?

O Adventure Journal Mod é uma reimaginação completa do conceito de diários no Minecraft. Esqueça os livros editáveis que se perdem facilmente - este mod oferece um **diário automático e inteligente** que documenta sua jornada sem qualquer esforço manual.

### ✨ **Principais Funcionalidades**

🔥 **Registro Automático de Mortes**
- Captura automaticamente cada morte com detalhes completos
- Localização exata, dimensão, causa e timestamp
- Nunca mais esqueça onde você morreu!

📍 **Sistema de Pontos de Interesse (POIs)**
- Marque locais importantes com comandos simples
- Descrições personalizadas
- Coordenadas precisas sempre à mão

💾 **Persistência Total**
- Todos os dados salvos automaticamente em JSON
- Funciona entre sessões e reinicializações
- Cada mundo mantém seus próprios registros

📚 **Interface Amigável**
- Livro somente leitura com design amigável
- Uma página dedicada para cada POI
- Sistema de cores otimizado para legibilidade

---

## 🎮 Como Usar

### Comandos Simples e Intuitivos:

```bash
# Marcar um local rapidamente
/poi add MinhaBase

# Adicionar com descrição detalhada  
/poi add "Mina de Diamante" "Rica em diamantes nível Y=12"

# Listar todos os pontos no chat
/poi list
```

### Funcionamento Automático:
1. **Entre no mundo** → Receba seu diário automaticamente
2. **Explore e aventure-se** → Mortes são registradas automaticamente  
3. **Marque locais importantes** → Use os comandos `/poi add`
4. **Consulte seu diário** → Todas as informações organizadas e acessíveis

### **Para Sobrevivencialistas**

### **Para Multiplayer**
- Cada jogador tem seu próprio diário personalizado
- Dados isolados por mundo/servidor
- Performance otimizada para muitos jogadores
